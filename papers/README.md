# Papers

PDFs linked from the portfolio. Filenames are referenced directly in
`index.html`, so keep them exactly as listed below.

Filenames must be lowercase with hyphens and no spaces, since spaces
become `%20` in URLs.

| Filename | Reference |
|---|---|
| `brassica-mir156-mir172.pdf` | Agarwal R., Dhaka N., Sharma R., Jatain A. "Genome-wide evolutionary analysis of precursor sequences of MIR156 and MIR172 family members in Brassica species." *Research Journal of Biotechnology* 16(4), April 2021, pp 81-92. |
| `wi-vi-poster.pdf` | Rahat H., Agarwal R. "Wi-Vi (Wireless Vision)." Student poster, AmiFest, Amity School of Engineering Technology, Amity University Haryana, 2018. |

## Adding a new PDF

1. Copy it here with a lowercase, hyphenated name
2. Link it from `index.html` as `papers/<filename>.pdf`
3. Add a `<span class="pub-badge">PDF</span>` to the row's `pub-meta` line
